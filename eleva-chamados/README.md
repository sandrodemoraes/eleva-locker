# Eleva Chamados

App da Eleva (câmeras, alarme, elétrica, energia solar) para anotar chamados por áudio no campo e a pessoa do escritório emitir a nota do cliente.

**Não faz parte do Eleva Locker.**

## Uso

1. No celular (Chrome): **Falar chamado**
2. Revise os campos e **Enviar para o escritório**
3. No escritório: copie o texto e marque a nota como feita

## Dev

```bash
npm install
npm run dev
```
