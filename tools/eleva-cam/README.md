# tools/eleva-cam

Scripts do PC Eleva Cam (site local + stream).

| Arquivo | Uso |
|---------|-----|
| `INICIAR_SITE.bat` / `iniciar_site.sh` | Sobe o Flask (`/eleva-cam`) |
| `INICIAR_STREAM.bat` | MediaMTX + ffmpeg → YouTube |
| `env.stream.example` | Modelo da chave YouTube + RTSP |
| `mediamtx.yml.example` | Config MediaMTX |

Guia completo: `docs/ELEVA_CAM_SETUP_PC.md`
