# ELEVA LOCKER

Sistema inteligente de armários para recebimento e retirada de encomendas.

## Tecnologias

- Python
- Flask
- SQLite
- ESP32
- HTML
- CSS
- JavaScript

## Porta padrão

15000

## Subir no Windows

```cmd
git checkout cursor/recuperar-servidor-antigo-615b
pip install -r requirements.txt
tools\criar_atalho_desktop.bat
```

Ou: `iniciar_elevalocker.bat` → http://localhost:15000
